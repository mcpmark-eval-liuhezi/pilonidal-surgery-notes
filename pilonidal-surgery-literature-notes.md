**Search run:** live PubMed database search executed for this pass (advanced search), term: *pilonidal sinus disease surgical treatment outcomes*, date window 2020/01/01 → present (roughly the last five years).

## Notes on the search

- **Sequencing restriction (honest limitation):** the search window was capped at 2020 onward, so many minimally invasive series report short- to medium-term recurrence rather than long-term outcomes; the strongest anchor for a ≥5-year synthesis would be a long-term cohort with explicit recurrence and infection endpoints, which a follow-up pass should target.
- **No padding:** items outside the recurrence-and-infection surgical-outcomes focus were excluded rather than listed, so the list is not padded with tangential papers.
